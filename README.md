【一、运行环境要求】
1. Linux 桌面环境（需要可用的 DISPLAY / Wayland，用于弹出 Chrome 窗口）
2. 已安装 Google Chrome 或 Chromium
   - 推荐: google-chrome-stable
   - 也可设置环境变量 CHROME_PATH 指向 chrome 可执行文件
3. 已安装 Python 3.10 或更高版本（含 python3-venv / python3-pip）
4. 网络环境：本机开启美区（US）代理，或在控制台左侧填写代理模板

Ubuntu / Debian 安装 Chrome 示例:
  wget -q https://dl.google.com/linux/direct/google-chrome-stable_current_amd64.deb
  sudo apt-get install -y ./google-chrome-stable_current_amd64.deb

【二、快速启动步骤】
1. 首次使用请在项目目录执行:
     chmod +x 1_首次运行_安装依赖并启动.sh 2_启动控制台.sh
     ./1_首次运行_安装依赖并启动.sh
2. 之后日常使用直接执行:
     ./2_启动控制台.sh
3. 浏览器会自动打开控制台页面：http://127.0.0.1:8765
   若未自动打开，请手动访问该地址。

无图形界面 / SSH 无 X 转发时无法弹出 Chrome，请在桌面环境或 VNC/XRDP 会话中运行。

【三、自定义填写支付卡 & 跑号说明】
1. 填写支付卡（必填）：
   - 在网页左侧【全局配置与内联免税绑卡】区域，填入你自己的 Visa 或 Mastercard 外币卡：
     * 卡号（16位数字）
     * 有效期（月 / 年，如 08 / 29）
     * 安全码（3位 CVC）
     * 持卡人英文姓名
     * 免税邮编默认已填好 97201（美国俄勒冈免税州），无需修改
   - 填写后点击【💾 保存配置】。
   - 注：脚本内置严格 0 元消费保护，仅在结账弹窗确认为 US$0.00 时才会点击订阅，全程 0 扣费。

2. 批量导入 Google 账号：
   - 在网页右侧【批量放号导入区】粘贴账号（每行一个），支持以下任意格式：
     * 邮箱----密码----辅助邮箱
     * 邮箱----密码----辅助邮箱----2FA密钥
     * 邮箱----密码----2FA密钥
   - 点击【➕ 一键导入账号列表】。

3. 开始全自动执行：
   - 点击单个账号右侧的【▶ 执行】或顶部的【▶ 批量全自动执行】。
   - 脚本会自动完成：
     Step 1: 自动登录 Google 并通过辅助邮箱 / 2FA 验证
     Step 2: 内联免税绑卡 + 首层 12 个月免费包 (US$0.00)
     Step 3: 叠加二层 6 个月免费包 (US$0.00 -> 18个月)
     Step 4: 叠加三层 6 个月免费包 (US$0.00 -> 24个月封顶)
     Step 5: 自动前往 Google Play 取消自动续订，锁死 2 年到期权益并截图验真
